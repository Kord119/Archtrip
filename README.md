# Archtrip

Локальный ИИ-агент для поиска билетов на поезда и самолёты. Работает на связке
Ollama (локальная языковая модель) и CrewAI (оркестрация агентов).

Задумка простая: модель крутится на моём компьютере, а в интернет ходят только
инструменты для получения расписаний и цен. Никакие данные кроме поисковых
запросов наружу не уходят.

## Что умеет

- Ищет поезда между городами и показывает цены по типам вагонов:
  плацкарт, купе, СВ, сидячий.
- Ищет авиабилеты через API Aviasales.
- Может просто полазить по интернету и собрать информацию по теме
  (через DuckDuckGo).
- Фильтрует результаты по времени отправления: утро, день, вечер, ночь.
- Сравнивает варианты и предлагает лучший по цене и времени.

Цены на поезда берутся из неофициального API ticket.rzd.ru (библиотека rzd-api),
поэтому они настоящие, а не выдуманные моделью. Если API недоступен, агент
честно пишет, что показывает оценку по тарифам.

## Как устроено

Три агента работают по очереди:

1. Flight Scout — ищет авиабилеты.
2. Train Specialist — ищет поезда и цены по вагонам.
3. Travel Analyst — сравнивает результаты первых двух и даёт рекомендацию.
   Сам в интернет не ходит, использует только то, что нашли остальные.

Модель по умолчанию — qwen3.5:9b через Ollama. Можно поставить любую другую,
которая нормально тянет function calling.

## Требования

- Python 3.10 или новее
- Установленный Ollama и скачанная модель (хватит 8-9 млрд параметров)
- Около 8 ГБ оперативной памяти

## Установка

    git clone https://github.com/Kord119/Archtrip.git
    cd Archtrip

    python -m venv venv
    venv\Scripts\activate          # Windows
    # source venv/bin/activate     # Linux, Mac

    pip install -r requirements.txt

Дальше нужно завести файл с ключами. Скопируйте шаблон и заполните его:

    copy .env.example .env         # Windows
    # cp .env.example .env         # Linux, Mac

Ключи нужны только для двух сервисов, оба бесплатные:

- Aviasales (Travelpayouts) — регистрация на travelpayouts.com,
  ключ лежит в личном кабинете в разделе API.
- Яндекс.Расписания — ключ выдаётся на yandex.ru/dev/rasp.

Для РЖД ключ не нужен, цены приходят через библиотеку rzd-api.

Осталось скачать модель и запустить Ollama:

    ollama pull qwen3.5:9b
    ollama serve

## Запуск

    python main.py

На Windows можно просто дважды кликнуть по start_agent.bat — он сам
поднимет окружение и запустит программу.

Дальше всё в консоли: выбираете режим, вводите города, дату и желаемое
время суток, ждёте результат.

## Про точность цен

Цены на поезда настоящие, но РЖД использует динамическое ценообразование,
поэтому цифра может немного плавать в течение дня. Перед покупкой стоит
проверить её на rzd.ru. Агент помогает выбрать вариант, а не оформить билет.

## Про неофициальный API

Библиотека rzd-api обращается к внутреннему API сайта РЖД. Официального
публичного API для поиска билетов у РЖД нет, поэтому используется этот путь.
Он может сломаться, если РЖД поменяет внутренности сайта. Для личного
пользования работает нормально, для коммерческого я бы не рисковал.
